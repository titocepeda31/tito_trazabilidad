# Tito Trazabilidad

Copia inicial independiente de Tito POS (React/Vite y PHP/Slim 4). No incluye el historial original. No conectar a su API ni base de datos. Configurar una base MySQL y API independientes antes de ejecutar.

## Desarrollo

- Frontend: `npm install` y `npm run dev`; configurar `VITE_API_BASE_URL` en `.env.local`.
- Backend: instalar dependencias con Composer en `backend/`; configurar archivo privado local. Pendiente revisar SQL y preparar instalación y despliegue propios.
- Refine, garantías e integración tributaria: pendientes.
- Notificaciones push deshabilitadas hasta configurar aplicación propia.

Se excluyeron los scripts antiguos de instalación y despliegue, documentación operativa, pruebas y workflows. No desplegar hasta auditar la base de datos, completar la configuración y ejecutar pruebas de seguridad e inventario.
