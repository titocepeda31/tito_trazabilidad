# Tito Trazabilidad

Base independiente de Tito POS. Frontend React/Vite, backend PHP/Slim 4. Migración a Refine, facturación y garantías pendientes. No conectar a la API ni base de datos originales. Configurar VITE_API_BASE_URL con una API nueva. Notificaciones push desactivadas hasta configurar una aplicación propia. No desplegar antes de completar la copia y auditar el SQL.
