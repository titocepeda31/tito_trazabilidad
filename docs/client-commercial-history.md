# Historial comercial del cliente
Nueva página completa en Clientes → Historial. API GET /clients/commercial/{id}/history?tab=...&page=... con administrador de empresa, identidad explícita, cliente activo/inactivo, paginación 25 registros. Siete vistas: cotizaciones, reservas, ventas, productos por línea vendida, números de serie históricos y reversas, devoluciones, evaluaciones. Ventas incluyen vínculo explícito por client_id y, cuando nulo, serial_sale_snapshots o credit_accounts; no asociar por nombre/RUT. No implica propiedad actual ni saldos de cobro. Cotizaciones y reservas incluyen estado efectivo de vencimiento. Sin migración nueva; requiere esquema existente hasta 022, incluyendo 013–018 y 020–022. No incluye aún casos de garantía, contactos comerciales, facturas/DTE, cuentas por cobrar consolidadas ni navegación directa a cada documento. Pruebas pendientes: empresa/rol, histórico desvinculado, ventas directas/entregas, anulaciones/reventa y reversas, reserva vencida/parcial, paginación y regreso a listado.
