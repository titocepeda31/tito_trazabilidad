# Cobranza comercial — primera parte
Clientes → Historial → Cuentas por cobrar → Ver / abonar. Consulta paginada por empresa y cliente, usando el libro existente credit_accounts/payments/adjustments/refunds y API /credit/accounts/{id}. Permite registrar abonos ya recibidos con medio y referencia; reutiliza ruta transaccional e idempotente existente, saldo validado y caja. No genera nuevas cuentas, ventas ni inventario; no confirma banco, no emite DTE. Sin migración. Anticipos antes de entrega, ventas a plazo desde cotización, reversa serializada de crédito y reasignación de abonos requieren diseño siguiente; no habilitar venta serializada a crédito por flujo heredado sin adaptar reversas. Pruebas pendientes.
