# 036 — base DTE (sin emisión)
Administración Documentos tributarios. Configuración versionada por empresa a partir de perfil/RUT válido, giro, código de actividad, comuna, base de precios declarada y referencia. Sin secretos en BD/React; no emite. Consulta de desarrollo OpenFactura fija GET https://dev-api.haulmer.com/v2/dte/organization, clave mediante variable de entorno privada TITO_OPENFACTURA_DEV_KEY_<business_id> del backend, cURL TLS sin redirecciones; no registra clave ni respuesta íntegra. Consulta no probada, RUT sandbox puede diferir. Documentación oficial https://docsapi-openfactura.haulmer.com/ y https://www.sii.cl/destacados/factura_electronica/guia_despacho.html. Borrador interno 33/39 por venta vigente sin devoluciones/ajustes; snapshot emisor, receptor, detalle/series, condiciones comerciales, total de venta y base declarada. No calcula IVA, no genera folio, XML, PDF fiscal, no transmite. Factura exige RUT histórico consistente y ficha tributaria completa. Una venta un borrador activo, UUID, descarte auditado, se permite recrear con nueva revisión; no anula venta ni cambia caja/stock/deuda. Revisar DTE emitidos externamente antes de emisión futura. Pendiente definir IVA/afecto/exento por línea, redondeo y precios, voucher boleta y pago, integración sandbox segura, guías parciales/referencias, NC/ND, validación previa a emisión, idempotencia proveedor y reconciliación de incertidumbre, PDF/XML/folio/estados y autorización real. No usar borradores como documentos tributarios. Requiere 036 después de 035, pruebas de PHP/SQL y validación contador.
