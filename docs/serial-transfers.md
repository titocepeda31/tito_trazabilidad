# Traslados por serie — fase 2
No requiere migración nueva: utiliza 009 y el historial existente warehouse_transfers y serial_unit_events. En Bodegas, al agregar producto serializado se cargan series disponibles en origen; la cantidad deriva de selección, máximo 500 por producto. Se admite mezcla con productos no serializados. El servidor valida empresa/producto/bodega/estado, concilia antes y después, actualiza saldos y ubicación de cada serie y registra evento con ID de traslado, nombres de bodegas y motivo, todo en una transacción. El total global no cambia. Hash conserva formato anterior para productos comunes, incluye series normalizadas para serializados; reintento se reconoce antes de validar disponibilidad. Se consulta detalle del traslado desde eventos JSON; no duplica tabla. Pendientes: recepción a bodega elegida, ventas, devoluciones, migración stock previo y pruebas de concurrencia/rollback/reintentos/aislamiento. No se han ejecutado pruebas PHP/Vite/DB.
