# UF oficial automática
Fuente: Banco Central de Chile, API BDE, serie F073.UFF.PRE.Z.D. Registrar y habilitar una cuenta en https://si3.bcentral.cl/estadisticas/Principal1/Web_Services/acceso_api.html y obtener el API Key Token. En cPanel, guardar SOLO en configuración privada del backend: variable de entorno TITO_BCCH_API_TOKEN o clave bcch_api_token en backend/private/config.php (archivo real no versionado). Nunca colocar en Vercel frontend, GitHub, ni enviar por chat. Requiere PHP cURL, HTTPS saliente y certificado CA válido.

El panel consulta por fecha; si no hay valor registrado, solicita la fecha exacta a la API mediante POST /currency/uf/sync. Reutiliza el valor de la empresa si existe. Botón de actualización explícita permite consultar de nuevo y, si cambia la fuente o el valor, agrega una nueva versión, preservando las antiguas. No modifica precios, ventas o borradores históricos. La conversión usa únicamente el valor de la fecha pedida; sin tasa no convierte. El respaldo manual requiere referencia de fuente y no se presenta como consulta oficial. Si hay una tasa manual existente, la consulta automática no la reemplaza sin actualización explícita.

Sin SQL nuevo; usa 038. No hay cron: consulta al abrir panel y seleccionar fecha. Futuras cotizaciones/ventas deberán exigir la tasa correspondiente desde el servidor. Validar token, conectividad, datos reales incluidos fines de semana, respuestas erróneas, reintentos, concurrencia, manual vs oficial, aislamiento y frontend. Las pruebas de parser usan fixtures, no certifican la conexión real.
