# Alcance de sucursales y cotizaciones
Importar 005_user_branches.sql después de 004 y antes de desplegar el backend. Los usuarios sin alcance explícito conservan comportamiento anterior. En Roles y permisos, asignar un rol personalizado y configurar acceso general o sucursales específicas. Selección vacía deniega stock; no equivale a toda la empresa. Las restricciones se aplican en API por ruta; el endpoint de inventario por sucursal filtra empresa, usuario, sucursal, bodega y producto. La asignación no modifica caja ni stock. Retirar el rol devuelve acceso heredado y elimina alcance; usar desactivación de usuario para revocar acceso. La edición de sucursales impide desactivar una asignada.

Los permisos de venta y cotización no están disponibles con alcance seleccionado porque los registros existentes no identifican sucursal histórica de manera confiable. No se infiere sucursal por bodega actual. Se agregó permiso quotes.create de alcance general que requiere inventario y consulta de cotizaciones, permite únicamente precios de lista calculados por el servidor; descuentos y conversiones siguen reservados al administrador. El catálogo de permisos no concede acceso a operaciones no auditadas.

Pruebas de aceptación: dos sucursales con bodegas y stock diferente, usuario de prueba restringido a una o ambas; verificar stock y acceso directo denegado a /products, /warehouses/stock, /sales y /quotes. Probar selección vacía, empresa ajena, cambio de rol y revocación de sesión. Probar cotización válida, precio manipulado, permiso faltante y conversión denegada. Las operaciones que ya comenzaron pueden finalizar. No se han ejecutado pruebas en producción.
